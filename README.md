
# Personal Portfolio Website

A responsive personal portfolio website created to display my projects, skills, and background.

## Features

- Responsive design for Desktop, Tablet, and Mobile devices.
- Clean UI structure using Flexbox and Bootstrap Grid.
- Custom styling built with HTML and CSS.

## Built With

- HTML5
- CSS3
- Bootstrap 5
- Git & GitHub Pages

## Project Structure

- index.html: Main entry file
- style.css: Custom styles and responsive queries
- assets/: Image assets and resources
